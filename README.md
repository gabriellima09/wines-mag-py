# wines-mag-py

Project dedicated to the report for the **Fundamentals of Data Science with Python [60h]** course at **SENAI Suzano**.

This project is based on the dataset `winemag-data-130k-v2.csv` and aims to explore and analyze wine data using data science tools and techniques in Python.

## Objective

The main goal of this project is to perform exploratory data analysis on wine data, utilizing charts, descriptive statistics, and visualization techniques to extract valuable insights. Some of the tasks performed include:

- Data loading and preprocessing
- Descriptive analysis and data visualization
- Investigation of patterns and correlations between variables

## Project Structure

- `main.py`: Main script containing the analysis and data visualizations generation.
- `data/`: Folder containing the `winemag-data-130k-v2.csv` file used for analysis.
- `img/`: Folder to store generated charts and images.
- `docs/`: Folder to store general documentation about the project.

## How to Run

1. Clone the repository:
    ```bash
    git clone https://github.com/gabriellima09/wines-mag-py.git
    ```
    
2. Install the dependencies:
    ```bash
    pip install -r requirements.txt
    ```

3. Run the analysis script:
    ```bash
    python wines_mag.py
    ```
